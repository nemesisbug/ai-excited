The Koi That Jumped the Moon — a golden koi leaps up an upward waterfall toward the moon: a single 1024×1024 image (`entry.png`) about persistence, the fish that refuses to swim downstream.

## Run it

```sh
node main.ts
```

This copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (default `/output`), refusing to run if the input is missing and verifying the copy is the same size as the source.
